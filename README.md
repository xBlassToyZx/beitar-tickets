# בית"ר ירושלים | כרטיסים למשחקים

אפליקציית ווב לבחירת מושבים ורכישת כרטיסים למשחקי הבית באצטדיון טדי: מפת גושים אינטראקטיבית, תצוגת מושבים לפי שורות, שמירת מושבים זמנית, מנויים עונתיים וארנק כרטיסים דיגיטלי עם קוד QR.

> **פרויקט לימודי עם נתוני דמה.** זה לא אתר רשמי של המועדון, הוא לא מוכר כרטיסים אמיתיים, והתשלום מדומה. לוח המשחקים, המחירים והמכירות שנוצרים בהתקנה הם דוגמה בלבד. מספר המקומות בכל גוש תואם לאצטדיון האמיתי (31,434 מקומות).

## טכנולוגיות

| שכבה       | טכנולוגיה                                                   |
| ---------- | ----------------------------------------------------------- |
| Framework  | Next.js 15 (App Router), React 19                           |
| שפה        | TypeScript במצב strict                                      |
| מסד נתונים | SQLite דרך Prisma ORM 7 (driver adapter: better-sqlite3)    |
| ולידציה    | Zod                                                         |
| בדיקות     | Vitest: בדיקות יחידה ובדיקות אינטגרציה מול מסד נתונים אמיתי |
| איכות קוד  | ESLint, Prettier, GitHub Actions CI                         |

## התקנה והרצה

דרישות: Node.js 20.19 ומעלה (מומלץ 22, ראה `.nvmrc`).

```bash
git clone https://github.com/xBlassToyZx/beitar-tickets.git
cd beitar-tickets
npm install          # מתקין תלויות ומייצר את Prisma Client
cp .env.example .env # הגדרות מקומיות
npm run setup        # יוצר את מסד הנתונים ומכניס נתוני אצטדיון ומשחקים (כ-20 שניות)
npm run dev          # http://localhost:3000
```

להתחלה מחדש עם מסד נתונים נקי: `npm run db:reset`.

## פקודות

| פקודה                                | מה היא עושה                          |
| ------------------------------------ | ------------------------------------ |
| `npm run dev`                        | שרת פיתוח                            |
| `npm run build` / `npm start`        | בנייה והרצה בפרודקשן                 |
| `npm test`                           | כל הבדיקות                           |
| `npm run lint` / `npm run typecheck` | בדיקות סטטיות                        |
| `npm run format`                     | עיצוב קוד עם Prettier                |
| `npm run db:migrate`                 | הרצת migrations                      |
| `npm run db:seed`                    | נתוני אצטדיון, משחקים ומכירות מדומות |
| `npm run db:reset`                   | מחיקת מסד הנתונים ובנייה מחדש        |

כדי להתקין בלי מכירות מדומות (אצטדיון ריק): `SEED_SIMULATED_SALES=false npm run db:seed`.

## מבנה הפרויקט

```
src/
├── app/                  # דפים ו-API (Next.js App Router)
│   ├── api/              # REST: זמינות, מושבים, שמירה, תשלום, מנויים
│   ├── matches/[slug]/   # בחירת מושבים למשחק
│   ├── season/           # מנויים עונתיים
│   └── wallet/           # הכרטיסים שלי
├── components/           # רכיבי UI (מפת אצטדיון, מושבים, סל, כרטיס)
├── domain/               # לוגיקה טהורה בלי תלות בשרת: גושים, שורות, מחירים, חוקים
├── server/               # שירותים מול מסד הנתונים: זמינות, הזמנה, מנויים
├── lib/                  # כלי עזר משותפים (פורמט, לקוח API)
└── middleware.ts         # מזהה קונה אנונימי בעוגייה
prisma/
├── schema.prisma         # מודל הנתונים
├── migrations/           # migrations של SQL
└── seed.ts               # נתוני התחלה
tests/integration/        # בדיקות מול מסד נתונים אמיתי
docs/ARCHITECTURE.md      # החלטות ארכיטקטורה
```
